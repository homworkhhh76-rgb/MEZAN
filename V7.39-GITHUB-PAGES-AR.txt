الميزان برو v7.39 — صفحات HTML فعلية لـ GitHub Pages

تم إلغاء الاعتماد على Hash Routing للقائمة الجانبية.
كل قسم رئيسي أصبح له ملف HTML مستقل حقيقي، مثل:
accounts.html = شجرة الحسابات
branches.html = الفروع
warehouses.html = المستودعات
employees.html = الموظفون والصلاحيات
settings.html = الإعدادات والطباعة
sales.html = المبيعات
purchases.html = المشتريات
products.html = الأصناف
... وبقية الأقسام.

جميع الصفحات تستخدم نفس قاعدة البيانات المحلية ونفس جلسة الدخول ونفس ملفات JavaScript، لذلك البيانات والمهام واحدة في كل الصفحات.

عند رفع النسخة على GitHub Pages ارفع محتويات ZIP كاملة كما هي في نفس المجلد، بما فيها جميع ملفات HTML وservice-worker.js وpages-bundle.js و.nojekyll.

Service Worker يقوم بحفظ ملفات الصفحات المستقلة في الكاش، ولا يقوم بتحويل صفحة فرعية مفقودة إلى الصفحة الرئيسية.
