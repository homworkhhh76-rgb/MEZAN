الميزان برو v7.40 — إصلاح التنقل على GitHub Pages

- ملفات HTML المستقلة ما زالت موجودة لكل صفحة، لذلك فتح accounts.html أو branches.html مباشرة يعمل.
- عند الضغط داخل القائمة الجانبية لا يعاد تحميل التطبيق ولا تضيع الجلسة.
- عنوان المتصفح يتغير إلى ملف الصفحة الحقيقي عبر History API، بينما نفس التطبيق يبقى مفتوحاً.
- تم تقوية استعادة جلسة ملف التفعيل من التخزين المحلي عند تحديث الصفحة أو فتح رابط صفحة مباشرة.
- زر الرجوع/التقدم في المتصفح يغير الصفحة داخل نفس التطبيق.
- الرفع إلى GitHub: ارفع جميع الملفات كما هي إلى نفس المجلد.
